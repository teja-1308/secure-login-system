# Secure Login System

Full-stack secure login system built with modern stack.

### Tech Stack
- **SQL:** Stored Procedure + Logging Table
- **Backend:** Node.js + Express
- **Frontend:** jQuery + AJAX validation
- **Tools:** Git, GitHub, VS Code

### Features
- Stored Procedure based authentication
- Server-side logging of all login attempts
- Client & Server validation
- REST API

### How to Run
1. npm install
2. node server.js
